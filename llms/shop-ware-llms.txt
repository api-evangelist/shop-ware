# Shop-Ware

> Shop-Ware is cloud-based auto repair shop management software. Its Partner API (V1 and V2) lets integrations read and manage a shop's repair orders, estimates, services, customers, vehicles, inventory, payments, staff, and more, scoped per tenant (shop), with an HTTPS webhook surface for near-real-time events. Authentication uses two required partner header credentials (X-Api-Partner-Id + X-Api-Secret). Generated by the API Evangelist enrichment pipeline.

## APIs
- [Shop-Ware Partner API V2 (recommended)](https://api.shop-ware.com/api-docs/public/v2/swagger.yaml): OpenAPI 3.0.1, cursor pagination
- [Shop-Ware Partner API V1](https://api.shop-ware.com/api-docs/public/v1/swagger.yaml): OpenAPI 3.0.1, offset pagination, full resource surface + webhooks
- [API docs (Swagger UI)](https://api.shop-ware.com/api-docs/index.html)
